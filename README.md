# 🎵 Resonance — Offline Music Platform

> A personal, offline-first music platform that turns your messy local audio files into a clean, Spotify-like library — fully on-device, no cloud required.

Built with **Flutter** · Clean Architecture · Riverpod · Isar · just_audio

---

## ❓ Why does the repo only contain `lib/` and `pubspec.yaml`?

This is intentional. Flutter projects contain two kinds of files:

| Kind | Where they come from | Included here? |
|---|---|---|
| **Your code** — `lib/`, `pubspec.yaml` | Written by hand | ✅ Yes |
| **Platform scaffolding** — `android/`, `ios/`, `windows/`, `.dart_tool/` | Auto-generated by `flutter create` | ❌ No |

The platform folders (`android/`, `ios/`, etc.) are **machine-generated boilerplate**. They are not hand-written, they differ between machines and SDK versions, and committing them pollutes the repo with thousands of generated lines. The correct workflow is to let the Flutter SDK generate them fresh on your machine — that's what Step 1 below does.

## 🚀 How to Run (first time setup)

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) ≥ 3.3.0 installed and on your PATH
- Android Studio **or** VS Code with the Flutter extension
- An Android device (USB debugging on) **or** an Android emulator running

Verify your environment:
```bash
flutter doctor
```
All relevant checkmarks should be green before continuing.

---

### Step 1 — Generate the platform scaffolding

Clone the repo and step into it:
```bash
git clone https://github.com/mxbn-mubeen/resonance.git
cd resonance
```

Run `flutter create` **inside the same folder** to generate `android/`, `ios/`, and the rest of the native shell. The `--project-name` flag must match the `name` field in `pubspec.yaml`:
```bash
flutter create --org com.mxbn --project-name offline_music_platform .
```

> **What happens:** Flutter generates `android/`, `ios/`, `web/`, `.dart_tool/`, etc. alongside the existing `lib/` and `pubspec.yaml`. Your code in `lib/` is **not touched**.

---

### Step 2 — Add Android permissions

Open `android/app/src/main/AndroidManifest.xml` and add these lines inside `<manifest>`, just above `<application>`:

```xml
<uses-permission android:name="android.permission.READ_MEDIA_AUDIO" />
<uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE"
    android:maxSdkVersion="32" />
<uses-permission android:name="android.permission.FOREGROUND_SERVICE" />
<uses-permission android:name="android.permission.FOREGROUND_SERVICE_MEDIA_PLAYBACK" />
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.WAKE_LOCK" />
```

Also open `android/app/build.gradle` and set:
```gradle
minSdkVersion 21
```
(Required by `just_audio` and `isar`.)

---

### Step 3 — Install dependencies

```bash
flutter pub get
```

---

### Step 4 — Generate Isar & Riverpod code

The Isar database schemas and Riverpod providers use code generation. Run this once (and again any time you change a schema or provider):

```bash
dart run build_runner build --delete-conflicting-outputs
```

---

### Step 5 — Run the app

Plug in your device (or start an emulator), then:

```bash
flutter run
```

Or open the project in **Android Studio** → select your device from the dropdown → press the green ▶ Run button.

## ✅ What's implemented vs. stubbed

| Module | Status |
|---|---|
| Folder scanning (`on_audio_query`) | **Done** — diffs by (mtime, size), skips unchanged files, zero spurious writes |
| Metadata Cleaner | **Done** — website blacklist, regex normalization, tested against real MP3s |
| Song Matcher (iTunes / MusicBrainz) | Clients wired, confidence scoring is `TODO` |
| Artwork Manager | **Done** — download → decode → resize → JPEG compress → cache; quality presets |
| Lyrics Manager | Priority chain stubbed (embedded → `.lrc` → online → cache) |
| Duplicate Detector | Hash + perceptual fingerprint tested; PCM decode step is `TODO` |
| Playlist Engine | Manual CRUD done; smart rules and AI playlists stubbed |
| Recommendation Engine | Interface + stub only |
| Playback Controller | **Done** — full `just_audio` + `audio_service` wiring, OS media notification |
| Isar schemas | **Done** — Song, Artist, Album, Playlist, History |
| Riverpod providers | **Done** |
| Player screen | **Done** — cinematic: blurred art backdrop, dominant-color tint, 3D card, animated transitions |
| Other screens | Widget trees bound to providers; ready to style |

Every `TODO` has a `// TODO(module):` comment pointing to exactly what needs wiring.

---

## 🔨 Suggested build order

1. Scanning + basic playback (no network) — get the app running with your local files
2. Metadata Cleaner → Song Matcher → confidence scoring
3. Artwork + Lyrics engines
4. Duplicate detection + Library Health report
5. Smart playlists → AI/mood playlists → Recommendation Engine
